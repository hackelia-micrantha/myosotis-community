# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to:

- `security.myosotis@micrantha.com`

Include the affected page, deployment, public artifact, or underlying Myosotis design requirement; reproduction steps; expected versus observed behavior; and likely impact.

Do not include real patient data, production credentials, private keys, or unrelated personal information.

## Scope

Reports may cover:

- public-site deployment or configuration;
- disclosure of private or sensitive project material;
- misleading public security or healthcare claims;
- broken provenance between public summaries and canonical source material;
- content injection, supply-chain, browser-policy, or hosting weaknesses;
- vulnerabilities in public examples or downloadable artifacts.

Normative protocol and SDK security issues are also accepted through this address and will be routed to the private core repository.

## Current maturity

Myosotis is currently a draft specification and early implementation effort. The public site is a design artifact, not a production or clinical service.

## Disclosure

Please allow reasonable time to investigate and coordinate a fix before public disclosure. No specific response or remediation SLA is promised at the current project stage.
